### OSINT Subdomain Discovery Tools

To find thousands of subdomains for your scanner, use these industry-standard tools.

#### 1. Install the Tools (Termux / Linux)
If you are on Termux, you first need to install Go, then the tools:
```bash
pkg install golang -y
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
go install github.com/tomnomnom/assetfinder@latest
# Make sure ~/go/bin is in your PATH
export PATH=$PATH:$(go env GOPATH)/bin
```

#### 2. Mass Discovery Commands
Run these commands to find subdomains for a target (e.g., safaricom.co.ke):

**Using Subfinder (Fastest):**
```bash
subfinder -d safaricom.co.ke -o subfinder_results.txt
```

**Using Assetfinder:**
```bash
assetfinder --subs-only safaricom.co.ke > assetfinder_results.txt
```

**Using crt.sh (No installation required):**
```bash
curl -s "https://crt.sh/?q=%25.safaricom.co.ke&output=json" | jq -r '.[].name_value' | sed 's/\*\.//g' | sort -u > crtsh_results.txt
```

#### 3. Merge & Clean for Your Scanner
Combine all results into one clean list for your `scanner.py`:
```bash
cat subfinder_results.txt assetfinder_results.txt crtsh_results.txt | sort -u > domains.txt
```
